## 8. Cross-cutting evidence qualifications

- The frozen handoff named a public `ModelLibrary.resolve` method that does not exist in the
  inspected staging class. Element-extension chains are resolved during
  `ModelLibrary.__init__`; runtime dataset and parameter binding proceeds through
  `ExperimentModel.resolve`, `resolve_data_model`, and item helpers.
- One objective is created per Experiment, but current objective results are combined into a
  dataset-keyed top-level mapping. The chapter therefore does not invent a nested
  per-Experiment result container or promise collision handling for repeated dataset labels.
- `OptimizationInfo.success` is not interpreted as proof of SciPy convergence; the result
  fields are described as diagnostics. The field named `covariance_matrix`, degrees-of-
  freedom count, log-coordinate standard errors, and global-Element CLP count have the
  implementation-specific limitations recorded in NM-15. Likewise, the computed package-
  version field, parameter-history population, and transient SVD calculation are not
  overstated as immutable provenance, a complete parameter trajectory, or retained arrays.
- The `forward` alignment branch does not reliably map a filtered match back to the original
  target-axis index. Directional behavior is therefore a maintainer-review item rather than
  a current guarantee.
- NNLS constrains the reduced inner coefficient vector. A target reconstructed through a
  negative CLP-relation factor can still be negative in the expanded full-label result.
- Current source still contains transitional older terms in some docstrings and support
  code. Those occurrences are maintenance evidence, not authority for chapter terminology.
- The full-surface matrix equation is scoped to the common-matrix teaching case. Per-solve
  vector notation covers ordinary coordinate slices, linked blocks, and the specialized
  flattened global-Element layout without changing the distinction between outer explicit
  parameters and inner CLPs.
