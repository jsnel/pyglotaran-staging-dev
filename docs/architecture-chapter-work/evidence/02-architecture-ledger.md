## Handoff/source discrepancy

The handoff reading map and one earlier planning sentence referred to `ModelLibrary.resolve`.
The current staging class has no such public method. Extension chains are handled in
`ModelLibrary.__init__` (`library.py:28–46`); execution-time dataset and parameter references
are handled by `ExperimentModel.resolve`, `resolve_data_model`, and item helpers. The section
uses the observed operation and does not reproduce the stale method name.
