## Packet-level cautions

- The Python QR-based variable-projection routine is not described as TIMP's
  partitioned algorithm.
- `ExperimentModel.residual_function` controls repeated ordinary and global-penalty
  objective calculation, while specialized global-result reconstruction later reads
  the DataModel-level field.
- The scalar sum-of-squares equation explains what SciPy minimizes; the code appends
  penalties to a residual vector rather than constructing that scalar expression.
