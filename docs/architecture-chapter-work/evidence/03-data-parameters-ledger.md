## Packet-level cautions

- `DataModel.data` is present on the resolved runtime object, but the field's association
  does not erase the conceptual distinction between a scientific DataModel and measured
  xarray values.
- The source contains transitional docstrings using older terminology. They are not used
  as current architectural evidence.
- “Non-negative explicit parameter” means the supported logarithmic outer-coordinate
  transformation. “NNLS” means a separate non-negativity restriction on inner CLPs.
- No unresolved verification item is required for Section 3.
